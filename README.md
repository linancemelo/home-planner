# 平面圖解讀 v1

在瀏覽器裡把平面圖變成牆、門、窗的 JSON，並疊回原圖。沒有後端，也還沒有 3D。

## 怎麼跑

```bash
npm install
npm run dev
```

開發伺服器是 [http://127.0.0.1:43123](http://127.0.0.1:43123)。

```bash
npm run build    # tsc 與正式包
npm test         # 用範例圖對照手標 JSON
npm run generate:fixtures
```

上傳 PNG 或 JPG，或直接開五張範例。辨識完可以下載 JSON，並在原圖上看牆（黑）、門（紅）、窗（藍），以及被挖掉的牆段（灰虛線）。

PDF 第一頁轉圖這版沒做。請先把第一頁輸出成 PNG 或 JPG。

## v1 / v2

v1 只做 2D：

1. 上傳平面圖
2. 遮掉圖框、圖說、指北針、比例尺，二值化並拿掉小文字
3. 只留牆、門、窗；看不清就略過並寫進 `meta.notes`
4. 依固定順序後處理，寫成 Floorplan JSON
5. 疊回原圖，並可下載 JSON

v2 才會做 3D：Three.js / React Three Fiber 的第一人稱。不鎖滑鼠指標，WASD 移動，牆壁碰撞，門可以開關。這版不要做 3D。

## 座標與假設

- 單位是公尺，原點預設在圖面左下（`coordinateOrigin: "bottom-left"`）
- 牆厚預設 0.12 m，`thicknessAssumed: true`
- 天花高預設 2.8 m，`ceilingHeightAssumed: true`
- 窗台高預設 0.9 m，`sillHeightAssumed: true`
- 圖上印的尺寸一律不採信。`scaleTrusted` 固定是 `false`
- 每像素公尺數是用雙線牆間距（或實心牆厚）假設 0.12 m 反推的。估不出來就用 0.02，並在備註說明

開口會從所屬牆段挖掉，所以 JSON 裡的牆不會穿過門窗。灰虛線只存在疊圖，不寫進牆陣列。

## 偵測實際做了什麼

這些是真的幾何程式，不是把結果寫死：

- Sauvola 二值化；黑白對比夠高時改走 Otsu，避免細線被吃掉
- 連通元件拿掉小文字、尺寸數字、符號；圓形小符號視為指北針
- 外框、角落圖說、帶刻度的比例尺會先遮掉
- 霍夫轉換找直線，再配對間距穩定的雙線。線中間夾著文字或間距忽寬忽窄，就不當牆
- 軸向的實心粗線用連續線寬聚類
- 平開門要同時有牆缺口、門扇、約四分之一圓弧，而且門扇長度要在開口的 ±10% 內。少一樣就略過，備註寫「疑似平開門但特徵不足」
- 拉門要有兩條錯開的近平行短線，而且沒有圓弧
- 窗要有至少兩條落在牆帶裡、彼此對齊的細線，沒有圓弧。線伸出牆外，或像封閉小矩形，就略過
- 後處理順序固定：刪掉短於約 0.3 m 的雜訊、合併近乎共線的牆、把開口投影上去並挖除、用幾何雜湊做穩定 id、寫備註
- 共線但中間沒有門窗特徵的缺口仍合併成一道牆，並註明「可能有未辨識開口」

## 還沒做 / 容易失敗的地方

- 沒有 opencv.js，也沒有模型
- 斜向的實心牆沒有專門的線寬掃描，主要靠霍夫；斜向雙線可以
- 孤立、短邊約 1.7 m 以內的封閉矩形會被當成家具拿掉
- 比例是假設的，不能拿來當施工尺寸
- 掃描歪斜、光線不均、牆線被家具蓋住時，寧可少報
- 單檔 HTML 可用 `vite-plugin-singlefile`，設定檔裡留了註解，預設沒打開

## 範例

手繪的合成圖與手標 JSON 在 `src/fixtures/`：

- `simple-room.png`
- `two-room.png`
- `l-shape.png`
- `clutter.png`
- `ambiguous-swing.png`

每個圖旁邊有同名的 `.expected.json`。

另外三張真實圖在 `src/fixtures/real-samples/`，`npm test` 會一併檢查數量與備註，而不是逐點對座標：

- `marketing-591.jpg`：銷售透視、591 浮水印、實心黑牆。只留近黑結構，木紋和淺色浮水印不會進牆。
- `furnished-en.jpg`：彩色家具平面、英文房名、指北針。牆以實心粗線為準。
- `interior-design-cad.jpg`：施工圖。右側標題欄、指北針會遮掉，圖上的尺寸數字不採信。

這三張的門窗仍可能少報。平開門要門扇加上約四分之一圓弧，而且圓弧不能只是沿著牆或木紋滑過去的假弧：弧上筆畫走向若跟切線對不齊，就當成木紋丟掉。牆墨沒有斷開時，只要鉸鏈在開口端，仍會挖開那段牆。缺門扇或缺圓弧只寫備註。拉門要牆帶裡兩條錯開的短平行線；約 1 m 以上的牆缺口若兩側有橫貫細線、中間是灰玻璃，也記成拉門並把開口對半錯開。窗要落在牆帶裡的細平行線；整段實心外牆不算窗。長約 1.8 m 以上、像空心牆腔的平行線組不列入窗，備註寫「待查：可能空心牆腔」。灰色玻璃隔間、斜向凸窗、沒有門扇的圓弧，這版不猜。比例一樣不可信。
